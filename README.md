# 🔐 Password Generator

A secure password generator built with Python.

## Features

- Generates passwords from 4 to 32 characters.
- Uses Python's `secrets` module for secure randomness.
- Guarantees at least one uppercase letter, lowercase letter, digit, and special character.
- Randomly shuffles password characters.
- Handles invalid user input.

## How to Run

**Requirements:** Python 3.8+

1. Clone the repository:
   ```bash
   git clone https://github.com/tenrovis/002-password-generator.git
   ```
2. Open the project folder:
   ```bash
   cd 002-password-generator
   ```
3. Run the program:
   ```bash
   python main.py
   ```

Enter a password length between 4 and 32 to generate your password.
